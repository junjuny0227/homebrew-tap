# junjuny0227/homebrew-tap

Homebrew formulae and casks for [Repot](https://github.com/junjuny0227/Repot) and [Doorplate](https://github.com/junjuny0227/Doorplate).

```sh
brew install junjuny0227/tap/repot
brew install --cask junjuny0227/tap/doorplate
```

`Formula/repot.rb` is generated by the Repot release workflow (`scripts/cli-packages.mjs`) when a release is published. Do not edit it by hand; change the template in the Repot repository instead.

`Casks/doorplate.rb` is rendered by `scripts/update-cask.sh` in the Doorplate repository from `packaging/homebrew/doorplate.rb.template` and the release's `.sha256` file. Do not edit it by hand.
